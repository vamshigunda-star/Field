# Field

Field is a free, open-source, offline-first Android app for coaches, PE teachers and fitness
professionals. It runs fitness testing events for athlete groups, records results on the spot
(including a built-in stopwatch), and grades each result against age- and sex-bracketed
percentile norms from published exercise-testing standards.
